# Assets

Image placeholders referenced by the main README. Add real files at these exact paths and they'll appear automatically — no README changes needed.

| Path | Used for |
|:--|:--|
| `banner.png` | Repository social preview / top-of-README banner |
| `hero.png` | Main README hero image |
| `screenshots/before.png` | Cloud-occluded input scene |
| `screenshots/after.png` | Reconstructed output scene |

Recommended: 1600px wide minimum, PNG or WebP. Before/after pairs should be the same scene for a fair comparison.
